# 관리자 5단계 위험도 및 WebRTC 카드 분리 설계

## 범위

- 관리자 화면의 위험도 표시, 필터, 정렬, 지도 마커와 범례를 5단계 공통 설정으로 통일한다.
- 홈 실시간 연결 목록의 각 항목을 독립 카드로 명확히 분리한다.
- 기존 라우팅, 인증, WebRTC 이동 및 연결 요청 모달 동작은 유지한다.

## 위험도 모델

정규 위험도는 `very_high`, `high`, `medium`, `low`, `very_low` 다섯 값으로 정의한다. 표시명, 색상, 지도 마커 색상, 정렬 우선순위는 공통 설정에서 관리한다. API 입력 타입은 기존 `danger`, `warning`, `caution`, `safe`를 포함하되, 공식 변환 기준이 없으므로 legacy 값은 새 등급으로 추측 변환하지 않고 `미분류`로 표시한다.

긴급 알림과 기존 고위험 목록 추출은 기능 호환을 위해 legacy `danger` 및 `warning`을 계속 판별한다. 이 판별은 사용자 표시 등급 변환과 분리한다. 숫자 위험 점수는 표시만 유지하고 등급 계산에는 사용하지 않는다.

## UI 적용

공통 `RiskBadge`와 위험도 helper를 통해 홈, 제보 목록, 제보 상세, 실시간 모니터링, 위험도 지도에서 동일한 설정을 사용한다. 필터는 새 5단계만 제공하고 legacy 또는 알 수 없는 값은 `미분류`로 표시하며 정렬 시 마지막에 둔다. 상세 단계형 지표는 매우 낮음부터 매우 높음 순으로 시각화한다.

## WebRTC 카드

목록은 일반 flex/grid 흐름과 16px 간격을 사용한다. 각 항목은 자체 배경, 대비되는 테두리, radius, shadow와 `overflow: hidden`을 갖는다. 위치·위험도, 영상, 상황 설명·연결 버튼은 한 카드 안에 유지한다. 목록 내부 스크롤과 카드 클릭 이동, 연결 버튼의 이벤트 전파 차단은 유지한다.

## 검증

- `npm run lint`
- `npm run build`
- 사용자 표시 영역에서 legacy 위험도 label 잔존 검색
- 5단계 필터, 배지, 정렬, 지도 마커와 WebRTC 카드 경계 수동 확인
