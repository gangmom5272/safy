# 혼잡도 계산 및 디버그 시각화 검증

## 문서 정보

- 관련 이슈: `S15P11A503-72`
- 검증일: 2026-07-22
- 혼잡도 규칙: `yolo-grid-v0.1`
- 탐지 모델: YOLO11n
- Python: 3.11.9
- GPU: NVIDIA GeForce RTX 4050 Laptop GPU

## 검증 목적

YOLO 사람 탐지 결과가 8×8 격자에 올바르게 배치되는지 확인하고,
C·L 점수가 계산된 근거를 디버그 이미지에서 확인한다.

이 검증은 실제 명/㎡를 측정하는 것이 아니라 MVP 임시 지표의
계산 과정과 재현성을 확인하는 것을 목적으로 한다.

## 디버그 이미지 표시 정보

- 초록색 선: 8×8 이미지 격자
- 파란색 박스: YOLO가 탐지한 사람 바운딩 박스
- 검은색 라벨: 칸별 `사람 수/점수`
- 빨간색 영역: L 계산에 선택된 최대 2×2 영역
- 상단 패널: 전체 사람 수, C, L 및 색상 범례

사람이 없거나 L이 0인 경우에는 의미 없는 빨간색 최대 영역을
표시하지 않는다.

## 자동화 테스트 시나리오

### 사람이 없는 경우

- 입력 사람 수: 0
- 예상 C: 0.0
- 예상 L: 0.0
- 빨간색 최대 영역: 표시하지 않음

### 각 격자 칸에 한 명씩 있는 경우

- 입력 사람 수: 64
- 각 칸 점수: 30
- 예상 C: 30.0
- 예상 L: 30.0

### 특정 2×2 영역에 사람이 몰린 경우

- 2×2 영역의 각 칸에 3명 배치
- 각 칸 점수: 90
- 예상 C: 5.62
- 예상 L: 90.0
- 최대 영역 좌표가 실제 밀집 위치와 일치하는지 확인

### 한 칸에 많은 사람이 있는 경우

- 한 칸의 사람 수: 10
- 칸 점수는 최대 100으로 제한
- 예상 C: 1.56
- 예상 L: 25.0

### 좌표가 정상 범위를 벗어난 경우

- 0보다 작은 좌표는 0.0으로 보정
- 1보다 큰 좌표는 1.0으로 보정
- 음수 인덱스로 잘못 배치되지 않는지 확인

## 실제 이미지 검증

### Ultralytics bus 이미지

- 이미지 크기: 810×1080
- 탐지 사람 수: 4
- C: 1.88
- L: 15.0
- 처리시간: 약 1.7초
- 사람 바운딩 박스 4개가 디버그 이미지에 표시됨
- 사람이 있는 네 칸에 `1/30`이 표시됨
- 가장 밀집된 2×2 영역에 빨간색 테두리가 표시됨

계산 확인:

```text
C = (30 × 4) / 64
  = 1.875
  = 1.88

L = (30 + 30 + 0 + 0) / 4
  = 15.0
```

### 빈 흰색 이미지

- 이미지 크기: 1280×720
- 탐지 사람 수: 0
- C: 0.0
- L: 0.0
- 처리시간: 약 1.75초
- 사람 박스와 빨간색 최대 영역이 표시되지 않음

## 실행 방법

```bash
cd ai

  --output runs/bus-congestion-debug.png
```

실행 결과 이미지는 `runs/`에 저장하며 Git에 포함하지 않는다.

## 검증 결과

- 동일한 입력에서 사람 수와 C·L 결과가 재현됨
- C·L 계산 위치를 디버그 이미지에서 확인할 수 있음
- 사람이 없는 경우와 경계 좌표가 안전하게 처리됨
- 현재 테스트 범위에서는 계산 규칙 자체의 오류가 발견되지 않음

## 현재 결정

현재 검증 자료만으로는 칸당 30점, 8×8 격자, 2×2 국소 영역을
다른 값으로 보정할 충분한 근거가 없다.

따라서 이번 작업에서는 `yolo-grid-v0.1` 계산 규칙을 유지한다.

향후 실제 SAFY 촬영 환경의 희소 인원, 일반 군중, 국소 밀집,
고밀도 군중, 야간·저화질 표본을 확보한 뒤 다음 항목을 다시 검토한다.

- 격자 크기
- 칸당 증가 점수
- 국소 영역 크기
- YOLO 유지 여부
- P2PNet 또는 DM-Count 비교 필요 여부

현재 처리시간은 단일 실행 결과이므로 FPS나 운영 성능 기준으로
사용하지 않는다. 성능 평가는 별도 이슈에서 반복 측정한다.
