# C·L 혼잡도 계산 규칙

## 문서 상태

- 규칙 버전: `yolo-grid-v0.2`
- 적용 범위: SAFY MVP
- 사용 모델: YOLO11n
- 상태: 대표 표본 기반 1차 보정
- 최초 구현 이슈: `S15P11A503-50`
- 보정 이슈: `S15P11A503-76`

이 규칙은 YOLO 사람 탐지 결과를 이용해 프레임의 전체 시각적 혼잡도 C와
국소 최대 혼잡도 L을 계산하기 위한 SAFY MVP 기준이다.

`yolo-grid-v0.2`에서는 8×8 격자와 C 계산 규칙을 유지하고,
한 칸에 사람이 집중될 때 L이 과도하게 낮아지는 문제를 보정했다.

## 입력값

YOLO가 탐지한 사람 바운딩 박스의 정규화된 중심 좌표를 사용한다.

각 좌표의 범위는 다음과 같다.

```text
0.0 <= centerX <= 1.0
0.0 <= centerY <= 1.0
```

범위를 벗어난 좌표는 0.0~1.0 사이로 제한한다.

YOLO 탐지 confidence의 평균은 C, L 또는 AI 분석 신뢰도로 사용하지 않는다.

## 8×8 격자

입력 프레임을 가로 8칸, 세로 8칸으로 나누어 총 64개의 이미지 칸을 만든다.

각 사람은 바운딩 박스 중심점이 포함된 이미지 칸 하나에 배치한다.

이 이미지 격자는 AI 내부 계산용이며, 실제 지도 격자나 100m 격자를
의미하지 않는다.

## 이미지 칸별 혼잡점수

각 이미지 칸의 사람 수를 다음 기준으로 0~100점으로 변환한다.

| 칸 내부 사람 수 | 혼잡점수 |
|---:|---:|
| 0명 | 0점 |
| 1명 | 30점 |
| 2명 | 60점 |
| 3명 | 90점 |
| 4명 이상 | 100점 |

계산식:

```text
Si = min(100, cellPersonCount × 30)
```

- `Si`: i번째 이미지 칸의 혼잡점수
- `cellPersonCount`: 해당 이미지 칸에 배치된 사람 수
- `30`: MVP 칸별 증가 점수

칸별 점수는 C 계산과 디버그 시각화에 사용한다.

## C: 전체 시각적 혼잡도

C는 64개 이미지 칸 혼잡점수의 평균이다.

```text
C = (S1 + S2 + ... + S64) / 64
```

출력 필드:

```text
visualCongestionScore
```

C는 프레임 전체에 사람이 얼마나 넓게 분포하는지 나타낸다.

국소 영역 한곳에만 사람이 집중된 경우에는 C가 낮고 L이 높을 수 있다.

## L: 국소 최대 혼잡도

서로 인접한 2×2 이미지 칸을 하나의 국소 영역으로 본다.

각 2×2 영역의 사람 수를 먼저 합산하고, 네 칸 평균에 해당하는 점수로
변환한 뒤 최대 100점으로 제한한다.

```text
N(r, c) = (
    personCount(r, c)
    + personCount(r+1, c)
    + personCount(r, c+1)
    + personCount(r+1, c+1)
)

W(r, c) = min(
    100,
    N(r, c) × 30 / 4
)

L = max(W(r, c))
```

- `N(r, c)`: 해당 2×2 영역의 전체 사람 수
- `W(r, c)`: 해당 2×2 영역의 혼잡점수
- `4`: 2×2 영역의 칸 개수
- `L`: 총 49개 2×2 영역 점수 중 최댓값

출력 필드:

```text
localPeakCongestionScore
```

## v0.1에서 발생한 문제

`yolo-grid-v0.1`은 각 칸 점수를 먼저 100점으로 제한한 뒤 네 칸의 평균을
계산했다.

```text
v0.1:
W(r, c) = (
    S(r, c)
    + S(r+1, c)
    + S(r, c+1)
    + S(r+1, c+1)
) / 4
```

이 방식에서는 한 칸에 사람이 많이 집중되어도 해당 칸이 먼저 100점으로
제한된다.

예를 들어 한 칸에 10명이 있고 나머지 세 칸이 비어 있으면 다음과 같이
계산됐다.

```text
(100 + 0 + 0 + 0) / 4 = 25
```

실제 국소 영역에는 10명이 있지만 L이 25점만 반환되어 국소 밀집을
과도하게 낮게 평가했다.

## v0.2 보정 내용

`yolo-grid-v0.2`는 2×2 영역의 사람 수를 먼저 합산한 뒤 점수를 계산한다.

동일하게 한 칸에 10명이 있는 경우 다음과 같이 계산된다.

```text
min(100, 10 × 30 / 4) = 75
```

이를 통해 한 칸에 집중된 사람도 국소 영역 전체 인원에 포함된다.

다음 규칙은 유지했다.

- 8×8 이미지 격자
- 칸당 30점
- 칸별 최대 100점
- C의 64칸 평균
- L의 2×2 국소 영역
- 최종 점수 범위 0~100

## 대표 표본 검증 결과

ShanghaiTech 정답 중심 좌표를 사용해 동일 표본에서 보정 전후를 비교했다.

| 장면 | 정답 인원 | C | v0.1 L | v0.2 L |
|---|---:|---:|---:|---:|
| SPARSE | 11 | 5.16 | 22.5 | 22.5 |
| NORMAL | 23 | 10.78 | 67.5 | 67.5 |
| LOCAL_DENSE | 29 | 8.75 | 57.5 | 100.0 |
| CROWDED | 172 | 16.25 | 97.5 | 100.0 |

보정 후 희소·일반 장면 결과는 유지됐고, 한 지역에 사람이 집중된
`LOCAL_DENSE` 표본의 L이 정상적으로 상승했다.

C는 변경하지 않았으므로 모든 대표 표본에서 기존 값이 유지됐다.

## YOLO 출력 검증 결과

동일한 대표 표본을 YOLO 탐지 중심 좌표로 계산한 결과는 보정 전후가
동일했다.

| 장면 | YOLO 탐지 인원 | C | L |
|---|---:|---:|---:|
| SPARSE | 16 | 7.50 | 30.0 |
| NORMAL | 23 | 10.78 | 45.0 |
| LOCAL_DENSE | 14 | 6.56 | 37.5 |
| NIGHT | 20 | 9.38 | 37.5 |
| LOW_QUALITY | 15 | 7.03 | 30.0 |

해당 YOLO 표본에서는 한 칸의 점수가 조기 상한에 도달하지 않았기 때문에
L 보정이 일반 장면 결과를 불필요하게 변경하지 않았다.

`LOCAL_DENSE`의 점수가 정답 좌표 기준보다 낮은 원인은 계산식이 아니라
YOLO가 29명 중 14명만 탐지한 미탐지 영향이다.

C·L 계산 규칙 보정과 탐지 모델의 정확도 문제는 별도로 관리한다.

## 상태별 처리

### 정상 프레임이며 사람이 없는 경우

```text
analysisStatus = COMPLETED
personCount = 0
visualCongestionScore = 0
localPeakCongestionScore = 0
```

### 분석할 수 없는 프레임

```text
analysisStatus = INVALID_FRAME
personCount = null
visualCongestionScore = null
localPeakCongestionScore = null
```

### 모델 추론 실패

```text
analysisStatus = FAILED
personCount = null
visualCongestionScore = null
localPeakCongestionScore = null
```

## API 데이터 계약

FastAPI 응답 필드는 변경하지 않는다.

```text
visualCongestionScore: number | null
localPeakCongestionScore: number | null
```

두 점수의 범위는 기존과 동일하게 0~100이다.

- C는 프레임 전체 시각적 혼잡도
- L은 가장 혼잡한 2×2 이미지 영역의 국소 혼잡도
- 실제 인구밀도 또는 명/㎡를 의미하지 않음

따라서 이번 보정으로 백엔드 API 필드나 타입 변경은 필요하지 않다.

## 테스트 범위

다음 상황을 자동 테스트한다.

- 사람이 없는 정상 프레임
- 각 칸에 한 명씩 있는 전체 분포
- 2×2 영역의 국소 밀집
- 한 칸에 사람이 집중된 경우
- 고밀도 영역의 100점 상한
- 0.0과 1.0 경계 좌표
- 범위를 벗어난 중심 좌표 보정
- 규칙 버전 일치

## 현재 방식의 한계

- YOLO는 고밀도 군중에서 가려진 사람을 놓칠 수 있다.
- 바운딩 박스 중심점은 실제 사람의 머리 좌표가 아니다.
- 촬영 거리, 카메라 각도와 화각을 보정하지 않는다.
- C와 L은 실제 인구밀도 또는 명/㎡를 의미하지 않는다.
- 대표 표본은 실제 SAFY 시민 제보 환경 전체를 대표하지 않는다.
- L이 100이면 그 이상의 밀집도 차이는 표현할 수 없다.

## 재검토 조건

다음 조건이 충족되면 규칙을 다시 검토한다.

- 실제 SAFY 촬영 환경의 대표 표본 확보
- 희소·일반·국소 밀집·고밀도 장면별 충분한 정답 데이터 확보
- 카메라 거리와 화각이 다른 표본 확보
- P2PNet 등 고밀도 보완 모델의 운영 적용 결정
- L 100점 포화 장면을 추가 단계로 구분할 요구 발생
- 백엔드와 위험도 단계 또는 임계값 계약 합의

P, G와 최종 위험도 계산은 메인 서버 담당 범위이므로 이 규칙에서
구현하지 않는다.
