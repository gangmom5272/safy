# YOLO 기준 모델 평가

## 목적

SAFY 혼잡도 분석에 사용하는 YOLO 기준 모델의 사람 계수 정확도와
혼잡도 계산 결과를 대표 표본에서 확인한다.

이번 평가는 다음 항목을 검증한다.

- YOLO 사람 탐지 결과와 정답 인원수의 차이
- 표본별 절대 오차
- 전체 및 시나리오별 평균 절대 오차(MAE)
- 탐지 결과로 계산한 C·L 혼잡도
- 이미지별 처리시간
- 평가 결과 JSON 생성 여부

## 기준 모델

| 항목 | 값 |
| --- | --- |
| 모델 | YOLO |
| 모델 버전 | yolo11n |
| 사람 클래스 | COCO class 0 |
| 혼잡도 규칙 | yolo-grid-v0.1 |
| 격자 | 8×8 |
| 국소 영역 | 2×2 |

## 평가 데이터

평가 표본은 Ultralytics COCO128의 YOLO 라벨을 사용해 선별했다.

- 공식 문서: https://docs.ultralytics.com/datasets/detect/coco128
- 전체 이미지 수: 128장
- 현재 평가 표본: 12장
- 시나리오별 표본: 각 3장
- 이미지와 실행 결과는 `runs/`에만 저장하고 Git에 포함하지 않는다.
- 이미지별 라이선스는 COCO 원본 메타데이터를 별도로 확인해야 한다.

## 표본 분류 기준

아래 기준은 운영 위험도 판정 기준이 아니라 평가 표본을 고르게
선별하기 위한 임시 규칙이다.

| 시나리오 | 선별 기준 |
| --- | --- |
| EMPTY | 정답 인원수 0명 |
| SPARSE | 정답 인원수 1~5명 |
| NORMAL | 정답 인원수 6~15명이며 L이 37.5 미만 |
| LOCAL_DENSE | 정답 라벨 중심 좌표로 계산한 L이 37.5 이상 |
| CROWDED | 정답 인원수 16명 이상 |

분류 우선순위는 다음과 같다.

1. 0명이면 `EMPTY`
2. 16명 이상이면 `CROWDED`
3. L이 37.5 이상이면 `LOCAL_DENSE`
4. 나머지는 인원수에 따라 `SPARSE` 또는 `NORMAL`

`LOCAL_DENSE`의 37.5는 실제 위험도 임계값이 아니라 국소 밀집
표본을 분리하기 위한 임시 선별값이다.

## 로컬 데이터 준비

COCO128은 약 7MB이며 다음 명령으로 내려받는다.

```bash
curl -L \
  https://github.com/ultralytics/assets/releases/download/v0.0.0/coco128.zip \
  -o runs/evaluation/coco128.zip
```

압축을 해제한다.

```bash
python -m zipfile -e \
  runs/evaluation/coco128.zip \
  runs/evaluation/
```

평가용 매니페스트 예시는 다음 파일에 있다.

```text
docs/yolo-baseline-manifest.example.csv
```

## 실행 방법

`ai` 디렉터리에서 실행한다.

```bash
python -m scripts.evaluate_yolo_baseline \
  docs/yolo-baseline-manifest.example.csv \
  --output runs/yolo-baseline-report.json
```

평가 결과 JSON은 `runs/yolo-baseline-report.json`에 저장되며
Git에 포함하지 않는다.

## JSON 구성

평가 보고서는 다음 정보를 포함한다.

- `model`: 모델 이름과 버전
- `summary`: 전체 평가 요약
- `scenarioSummaries`: 시나리오별 평가 요약
- `records`: 이미지별 정답, 예측, 오차, C·L, 처리시간

| --- | ---: |

시나리오별 결과는 다음과 같다.

| 시나리오 | 표본 | 실제 인원 | 예측 인원 | MAE |
| --- | ---: | ---: | ---: | ---: |
| EMPTY | 3 | 0 | 0 | 0.00 |
| SPARSE | 3 | 9 | 6 | 1.00 |
| NORMAL | 3 | 23 | 21 | 1.33 |
| LOCAL_DENSE | 3 | 31 | 26 | 2.33 |

## 결과 해석

`EMPTY` 표본에서는 오탐 없이 모두 0명으로 예측했다.

`SPARSE` 표본에서는 실제 9명 중 6명을 탐지해 작은 사람이나
가려진 사람을 놓치는 사례가 있었다.

`NORMAL` 표본에서는 실제 23명 중 21명을 탐지했으며 이미지별로
과대 탐지와 과소 탐지가 모두 발생했다.

`LOCAL_DENSE` 표본에서는 실제 31명 중 26명을 탐지했고 MAE가
2.33으로 가장 높았다. 현재 표본에서는 사람이 국소적으로 밀집될수록
가림과 작은 객체 때문에 YOLO의 과소 탐지가 증가하는 경향이 있다.

C와 L은 YOLO가 탐지한 사람 중심 좌표를 기반으로 계산한다.
따라서 사람 탐지 누락은 C와 L을 실제보다 낮게 계산하는 원인이 된다.

## 처리시간 해석 주의사항

첫 번째 이미지 처리시간에는 모델 로딩과 CUDA 워밍업 시간이
포함될 수 있다.

이번 실행에서 첫 표본 처리시간이 다른 표본보다 크게 측정되어
전체 평균 처리시간이 왜곡되었다. 따라서 현재 결과를 FPS나 운영
성능 기준으로 사용하지 않는다.

모델 간 처리시간 비교는 별도 이슈에서 다음 조건을 맞춰 수행한다.

- 동일 장비
- 동일 이미지
- 동일 입력 크기
- 사전 워밍업
- 반복 실행
- 평균과 분산 기록

## 현재 제한사항

- COCO128은 SAFY 시민 제보 영상의 실제 카메라 시점과 다르다.
- COCO128에는 정답 인원수 16명 이상의 표본이 없어
  `CROWDED` 시나리오를 검증하지 못했다.
- 실제 행사장, 지하철, 거리 군중 표본이 포함되지 않았다.
- 야간 및 저화질 표본 검증은 별도 품질 기준 이슈에서 진행한다.
- 현재 표본 수는 시나리오별 3장으로 통계적 결론을 내리기에 작다.
- 이미지별 원본 라이선스 메타데이터를 별도로 확인해야 한다.
- 처리시간에는 콜드 스타트가 포함될 수 있다.
