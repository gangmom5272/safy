# 실서비스 유사 표본 모델·C·L 오류 분리 검증

## 문서 상태

- 관련 이슈: `S15P11A503-160`
- 평가 모델: `YOLO:yolo11n`, `P2PNet:safy-p2pnet-v2-epoch3`
- 혼잡도 규칙: `yolo-grid-v0.2`
- 평가 상태: 독립 표본 20장 검증 완료
- 운영 규칙 변경: 없음

## 목적

QA에서 넓은 공원 장면이 높은 국소 혼잡도 `L=90`으로 분석된 사례가
확인되었다. 이 검증은 사람을 잘못 찾은 모델 문제와, 사람 위치가 맞아도
고정 8×8 격자가 장면의 원근과 실제 공간을 반영하지 못해 생기는 점수 문제를
분리하기 위해 수행했다.

평가 결과는 다음 두 후속 작업의 입력으로만 사용한다.

- `DETECTION_ERROR`: 모델 재학습 후보
- `SCORING_OVERESTIMATION`: 별도 C·L 규칙 보정 후보

이번 작업에서는 운영 모델, confidence 임계값과 `yolo-grid-v0.2`를 변경하지
않는다.

## 평가 표본과 사용 범위

P2PNet 학습과 validation에 사용하지 않은 JHU-CROWD++ v2.0 공식 `TEST`
분할에서 20장을 선택했다.

| 구분 | 장수 |
|---|---:|
| 저밀도 기준 장면 (`EMPTY`, `SPARSE`, `NORMAL`) | 10 |
| 넓게 분산되거나 원근으로 겹쳐 보이는 장면 | 5 |
| 실제 국소 밀집 장면 | 5 |
| 합계 | 20 |

표본의 출처, 분할, 라이선스, 이미지 해시와 머리 좌표 정답은 기존
`head-point-v1` manifest에서 가져온다. 공간 분포 수동 검수 결과는
[`service-like-spatial-review.csv`](service-like-spatial-review.csv)에 기록했다.

실제 시민 제보 이미지와 출처가 확인되지 않은 QA 이미지는 정량 평가와 학습에
포함하지 않았다. 시민 제보 이미지는 별도의 학습 동의 및 개인정보 처리 기준이
정해지기 전까지 학습 자료로 사용하지 않는다.

## 공간 분포 검수 기준

| 값 | 의미 |
|---|---|
| `WIDE_DISTRIBUTED` | 화면 또는 실제 공간에 넓게 분산됐지만 원근과 고정 격자로 일부가 겹쳐 보이는 장면 |
| `LOCAL_CLUSTERED` | 실제로 가까운 범위에 사람이 모여 있는 장면 |
| `NOT_APPLICABLE` | 두 장면을 비교하기 위한 저밀도 기준 표본 |

검수는 이미지 전체 맥락을 보고 수행한다. 이 값은 모델 예측으로 자동 생성하지
않는다.

## 오류 분리 기준

### DETECTION_ERROR

정답 인원수와 예측 인원수 차이가 다음 허용 오차보다 클 때 기록한다.

```text
tolerance = max(2명, ceil(정답 인원수 × 20%))
```

YOLO 또는 P2PNet 중 하나라도 기준을 넘으면 재학습 후보 목록에 넣는다. 또한
8×8 각 칸의 정답·예측 인원수 절대 차이 합을 함께 기록해 오탐·미탐 위치를
비교할 수 있게 했다.

### SCORING_OVERESTIMATION

사람이 넓게 분산된 것으로 수동 승인한 장면에서 정답 머리 좌표만으로 계산한
`L`이 75 이상이면 기록한다.

정답 좌표에서도 높은 `L`이 만들어진다면 탐지 모델이 완벽해져도 동일한 문제가
남는다. 따라서 이 경우는 모델 재학습만으로 해결하지 않고 C·L 계산 규칙의
보정 대상으로 분리한다.

## 실행 방법

원본 이미지, 가중치, JSON 보고서와 시각화 결과는 `runs/`에만 저장한다.

```bash
python -m scripts.evaluate_service_like_models \
  runs/evaluation/jhu-test-holdout-manifest.csv \
  --spatial-review docs/service-like-spatial-review.csv \
  --p2pnet-root runs/candidate-models/p2pnet \
  --weight-path runs/p2pnet-finetune-v2-balanced-search/epoch-003.pth \
  --device cuda \
  --thresholds 0.5,0.55,0.6,0.65,0.7 \
  --output runs/evaluation/service-like-model-scoring-validation.json \
  --visualization-directory \
    runs/evaluation/service-like-model-scoring-visualizations
```

각 시각화는 같은 이미지 위에 다음 세 패널을 만든다.

1. 정답 머리 좌표와 정답 C·L
2. YOLO 중심 좌표와 C·L
3. P2PNet 머리 좌표와 C·L

초록색은 8×8 격자, 자홍색 사각형은 최대 점수를 만든 2×2 영역이다.

## 검증 결과

### 전체 결과

| 항목 | 결과 |
|---|---:|
| 평가 표본 | 20장 |
| `DETECTION_ERROR` 표본 | 16장 |
| `SCORING_OVERESTIMATION` 표본 | 5장 |
| 넓은 분산 장면 | 5장 |
| 실제 국소 밀집 장면 | 5장 |

| 모델 | 인원수 MAE | C MAE | L MAE |
|---|---:|---:|---:|
| YOLO11n | 12.05 | 3.46 | 31.75 |
| P2PNet v2 epoch3 | 12.70 | 3.98 | 24.88 |

전체 평균만으로 모델 하나를 선택하면 장면별 차이가 가려진다.

| 장면 | 모델 | 인원수 MAE | C MAE | L MAE |
|---|---|---:|---:|---:|
| 저밀도 기준 10장 | YOLO | 0.70 | 0.33 | 3.75 |
| 저밀도 기준 10장 | P2PNet | 7.70 | 3.30 | 27.75 |
| 넓은 분산 5장 | YOLO | 18.20 | 4.50 | 60.00 |
| 넓은 분산 5장 | P2PNet | 13.80 | 3.22 | 31.50 |
| 실제 국소 밀집 5장 | YOLO | 28.60 | 8.69 | 59.50 |
| 실제 국소 밀집 5장 | P2PNet | 21.60 | 6.10 | 12.50 |

저밀도에서는 YOLO가 안정적이고, 넓은 분산 및 국소 밀집 표본에서는 P2PNet이
상대적으로 낫다. 두 모델을 함께 실행하고 검증된 오탐 게이트를 적용하는 현재
방향과 일치한다.

### C·L 과대평가 분리 결과

`WIDE_DISTRIBUTED` 5장은 정답 좌표로 계산해도 모두 `L=75~100`이었다.
반면 `LOCAL_CLUSTERED` 5장도 `L=75~100`이었다. 즉 현재 L은 두 유형을 구분하지
못한다.

이는 8×8 셀이 이미지 좌표만 사용하기 때문이다. 멀리 있는 사람들은 실제로
떨어져 있어도 화면 상단의 작은 영역에 투영되며, 같은 2×2 창에 들어가 높은
점수를 만든다. 따라서 이 다섯 사례는 탐지 정확도만 올려서는 해결되지 않는다.

C·L 보정 후보는 다음과 같다.

```text
jhu-test-0416
jhu-test-1009
jhu-test-1870
jhu-test-2016
jhu-test-3765
```

향후 `yolo-grid-v0.3` 후보에서는 원근 보정, 카메라별 ROI 또는 화면 세로 위치에
따른 셀 면적 보정을 검토한다. 보정안은 실제 국소 밀집 장면의 L이 낮아지지 않는지
동일 20장과 기존 회귀 표본으로 비교한 뒤 별도 이슈에서 적용한다.

### confidence 임계값 민감도

| 밀도 그룹 | 임계값 | 인원수 MAE | 평균 과대계수 | 평균 과소계수 |
|---|---:|---:|---:|---:|
| 저밀도 | 0.50 | 7.70 | 4.50 | 3.20 |
| 저밀도 | 0.60 | 7.20 | 3.70 | 3.50 |
| 저밀도 | 0.70 | 6.50 | 2.90 | 3.60 |
| 고밀도 | 0.50 | 17.70 | 7.40 | 10.30 |
| 고밀도 | 0.60 | 17.10 | 5.20 | 11.90 |
| 고밀도 | 0.70 | 16.40 | 2.60 | 13.80 |

임계값을 높이면 저밀도 오탐과 평균 과대계수는 줄지만 고밀도 평균 과소계수는
계속 증가한다. 이 표본에서 특정 임계값의 평균 MAE가 작더라도 고밀도 사람을 더
놓치는 방향이므로 전역 confidence 임계값만 변경하지 않는다.

## 후속 작업 분리

### 모델 재학습 후보 (`S15P11A503-146` 입력)

16개 `DETECTION_ERROR` 표본의 정답·예측 좌표와 3패널 시각화를 입력으로 사용한다.
특히 다음 두 유형을 분리한다.

- 저밀도 P2PNet 대량 오탐: 빈 배경과 반복 질감의 hard negative
- 원거리·밀집 YOLO/P2PNet 미탐: 작은 머리와 가림이 많은 positive

원본 JHU-CROWD++ 라이선스 범위 안에서만 재학습하고, 시민 제보 이미지는 자동으로
학습 데이터에 넣지 않는다.

### C·L 규칙 보정 후보

5개 `SCORING_OVERESTIMATION` 표본과 5개 `LOCAL_CLUSTERED` 표본을 한 쌍의 회귀
세트로 유지한다. 새 규칙은 분산 장면의 L을 낮추면서 실제 밀집 장면의 L을
보존해야 한다.

현재 운영 규칙은 `yolo-grid-v0.2`로 유지한다. 보정 수식과 임계값은 별도 버전과
별도 테스트로 제안한다.

## 한계

- 평가 표본은 20장으로 작으며 실제 시민 제보 분포 전체를 대표하지 않는다.
- JHU-CROWD++ TEST는 독립 홀드아웃이지만 촬영 장비와 장소가 SAFY 운영 환경과
  완전히 같지는 않다.
- `WIDE_DISTRIBUTED`와 `LOCAL_CLUSTERED`는 이미지 맥락을 본 수동 검수 결과다.
- 현재 정답은 이미지상의 머리 좌표이며 실제 명/㎡ 또는 사람 사이 물리적 거리를
  제공하지 않는다.
- 따라서 이번 결과는 문제 유형을 분리하는 근거이며 새 운영 임계값의 확정 근거는
  아니다.
