# SAFY 관리자 추가 UI/UX 수정 설계

## 목표와 범위

현재 작업 트리에 반영된 관리자 5차 UI 변경을 유지하면서 제보 목록, 실시간 모니터링, 위험도 지도, 시스템 설정 화면만 추가 조정한다. 기존 SAFY Admin 테마와 상태 흐름을 보존하고 사용자 프론트엔드, 백엔드, 헤더, 사이드바, 테이블, 영상 카드, 지도 본문 디자인은 변경하지 않는다.

## 제보 목록

기본 검색 행은 통합 검색창, `상세조건`, 새로고침 아이콘, `필터 적용` 순서의 단일 행으로 만든다. 통합 검색창은 남은 너비를 차지하며 placeholder는 `검색어를 입력해 주세요. (예: 제보 ID, 주소, 지역 등)`을 사용한다. form submit을 공통 적용 경로로 사용해 Enter와 버튼 클릭이 같은 동작을 수행한다.

검색 적용 시 앞뒤 공백을 제거한다. 검색어가 `#`으로 시작하고 나머지가 숫자로만 구성된 경우에만 앞의 `#`을 제거한다. 숫자 검색과 일반 문자열 검색은 기존 통합 검색 범위를 그대로 사용한다. 현재 제보 목록은 로컬 데이터 필터링 구조이며 API 경로나 요청 타입은 변경하지 않는다.

상세조건 토글과 입력값 유지, 날짜 범위, 카테고리, 위험도, AI 분석 상태, 정렬 동작은 유지한다. 새로고침은 기존 필터 초기화 동작을 유지하며 접근성 레이블을 `필터 초기화 및 목록 새로고침`으로 명확히 한다.

## 실시간 모니터링

지역 검색과 위치 아이콘, 필터 상태, 초기화, 그리드 선택, WebRTC 흐름은 유지한다. 비선택 Select 값은 실제 조회 값과 분리된 빈 값으로 유지하고 화면 문구만 각각 `위험도`, `연결 상태`로 변경한다. Select에는 `위험도 선택`, `연결 상태 선택` aria-label을 적용한다. 사용자가 `전체`를 직접 선택하면 기존 전체 조회 조건으로 처리한다.

## 위험도 지도

콘텐츠 영역의 중복 제목과 필터를 감싸는 큰 카드 배경을 제거한다. 상단 필터 행은 지역, 날짜, 위험도, 행사, 초기화, 새로고침 아이콘, 필터 적용 순서로 구성하고 좁은 화면에서 줄바꿈한다. 레이어 fieldset과 즉시 토글 동작은 유지한다.

지역과 위험도는 draft 상태와 적용 상태를 구분한다. Enter 또는 `필터 적용`으로 적용 상태를 갱신하며 지역은 마커 위치 문자열, 위험도는 기존 위험도 비교 함수를 사용한다. 초기화는 draft와 적용 상태 및 레이어를 초기값으로 복원한다. 현재 로컬 데이터에는 재조회 소스가 없으므로 새로고침은 현재 적용 상태를 다시 반영하는 명시적 액션으로 유지하며 API 동작을 가장하지 않는다.

날짜와 행사 정보는 현재 마커 데이터에 존재하지 않는다. 두 컨트롤은 임의 데이터를 추가하거나 효과 없는 활성 필터로 두지 않고 비활성화한다. `현재 데이터에서 지원하지 않는 필터입니다` 안내를 title과 aria-label에 제공한다. 새 API나 Mock 필드를 만들지 않는다.

## 시스템 설정

헤더 아래의 System 소개 카드를 완전히 제거한다. `시스템 상태 요약`의 제목, 최근 업데이트 배지, 내부 상태 카드 네 개는 유지하되 이들을 감싸는 외부 흰색 카드의 배경, 테두리, 그림자, padding만 제거한다. 개별 카드와 하단 서버·WebRTC·제보·AI 상태 영역은 변경하지 않는다.

원본 `lastUpdatedAt`에는 초 정보가 없으므로 최근 업데이트는 기존 분 단위 문자열을 그대로 표시한다. 초를 임의 생성하거나 `:00`을 덧붙이지 않는다.

## 반응형과 접근성

기존 CSS 변수, 8px radius, 컨트롤 높이 38px과 기존 breakpoint를 재사용한다. 제보 및 지도 필터는 데스크톱에서 한 줄, 좁은 화면에서 검색창과 버튼 그룹이 자연스럽게 줄바꿈된다. 시스템 요약은 넓은 화면 4열, 중간 화면 2열, 작은 화면 1열을 유지한다. 아이콘 전용 버튼에는 aria-label과 title을 제공한다.

## 검증 기준

- `npm run lint`와 `npm run build`가 성공한다.
- 제보 검색의 Enter와 적용 버튼이 같은 submit 흐름을 사용하고 `123`, `#123`, 일반 문자열을 처리한다.
- 상세조건 토글 시 입력값이 유지되고 새로고침이 기존 초기화 동작을 수행한다.
- 모니터링 placeholder와 실제 필터 값이 분리되고 전체 옵션과 그리드 선택이 유지된다.
- 지도 지역·위험도 필터, 초기화, 새로고침, 적용, 레이어 토글이 상태 충돌 없이 동작한다.
- 지도 날짜·행사 필터가 데이터 미지원 상태를 명확히 전달한다.
- 시스템 소개 카드와 요약 외부 배경만 제거되고 실제 상태 데이터는 유지된다.
- 개발 서버가 응답하며 브라우저에서 네 화면과 반응형 줄바꿈, 콘솔 오류를 확인한다.
