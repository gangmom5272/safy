# 관리자 제보 상세조건 기본 닫힘 및 날짜 필터 간소화 설계

## 목표

- 홈에서 제보 목록으로 처음 이동하면 상세조건을 닫힌 상태로 표시한다.
- 제보 날짜 필터의 중복된 달력 아이콘과 불필요한 바깥 흰색 블록을 제거한다.
- 시작일과 종료일 입력 기능 및 각 입력의 기본 달력 버튼은 유지한다.

## 변경 설계

- `isDetailOpen`의 초깃값을 `false`로 변경한다.
- 날짜 범위 앞에 별도로 렌더링되는 `CalendarIcon` 컴포넌트를 제거한다.
- 날짜 범위 컨테이너는 배경, 테두리, 둥근 모서리, 바깥 패딩 없이 두 날짜 입력과 구분자만 배치한다.
- 각 날짜 입력은 독립적인 흰색 배경, 테두리, 둥근 모서리를 유지한다.
- 날짜 범위에 최대 너비를 적용해 상세조건의 두 열을 불필요하게 가득 채우지 않도록 한다.
- 기존 날짜 필터 값, 적용 방식, 초기화 방식은 변경하지 않는다.

## 반응형 처리

- 데스크톱에서는 날짜 입력 두 개를 한 줄에 간결하게 배치한다.
- 기존 상세조건 반응형 그리드는 유지하며 작은 화면에서도 입력이 컨테이너를 넘지 않도록 각 열을 `minmax(0, 1fr)`로 둔다.

## 검증

- 최초 제보 목록 진입 시 상세조건 영역이 렌더링되지 않고 버튼 문구가 `상세조건`인지 확인한다.
- 상세조건을 열었을 때 별도 앞쪽 달력 아이콘과 바깥 흰색 블록이 없고, 두 날짜 입력의 기본 달력 버튼은 남아 있는지 확인한다.
- 날짜 입력과 조건 적용이 기존과 동일하게 동작하는지 확인한다.
- `npm test`, `npm run lint`, `npm run build`, `npm run dev` 검증을 수행한다.

## 범위 제외

- 상세조건 내 다른 필터의 배치 또는 스타일 변경
- 날짜 필터 데이터 형식 및 검색 로직 변경
