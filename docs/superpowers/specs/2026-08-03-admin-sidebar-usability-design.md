# 관리자 사이드바 사용성 개선 설계

## 목표

관리자 페이지의 라우팅과 메인 콘텐츠 레이아웃을 유지하면서 좌측 사이드바의 정보 구조와 조작성을 개선한다. 핵심 변경은 메뉴 아이콘 추가, 주요 현황 UI 제거, 로그인 계정 정보를 사용하는 하단 계정 카드 추가다.

## 변경 범위

- `frontend-admin/src/components/layout/AdminSidebar.tsx`
  - 기존 `NavLink` 경로와 활성 상태 판별을 유지한다.
  - 상단 브랜드, 메뉴 아이콘, 하단 계정 카드를 구성한다.
  - 사이드바에서만 쓰이던 주요 현황 렌더링과 목데이터 import를 제거한다.
- `frontend-admin/src/index.css`
  - 기존 네이비·블루 디자인 토큰을 재사용해 사이드바 전용 스타일을 조정한다.
  - 사이드바 너비와 메인 콘텐츠 그리드는 변경하지 않는다.

라우터, 페이지, 지도, WebRTC, API, 통계 데이터 원본은 수정하지 않는다. 상단 헤더의 기존 계정 메뉴도 유지한다.

## 시각 구조

사이드바는 세 구역으로 구성한다.

1. 브랜드: 둥근 파란 배경의 방패 SVG, `SAFY`, `관제 콘솔 · 성동구`를 수평 배치하고 아래에 구분선을 둔다. 담당 지역 데이터가 인증 모델에 없으므로 `성동구`는 현재 단계의 표시용 문구로 사용한다.
2. 내비게이션: 홈, 제보 목록, 실시간 모니터링, 위험도 지도, 시스템 설정에 의미가 맞는 인라인 SVG를 추가한다. 아이콘과 문구는 한 행에 정렬하고 충분한 클릭 영역, hover/focus-visible, 둥근 활성 배경을 제공한다.
3. 계정 카드: `margin-top: auto`로 데스크톱 사이드바 하단에 배치한다. 원형 사용자 아이콘, 이름과 권한의 두 줄 정보, 별도의 로그아웃 버튼을 둔다. 카드 전체는 로그아웃 버튼으로 동작하지 않는다.

## 데이터와 동작

- 계정 이름은 `useAuth()`의 `user.displayName` 또는 `adminName`을 우선 사용하며, 값이 없을 때 `SAFY Super Admin`을 표시한다.
- 권한은 인증 모델의 역할을 사용한다. `SUPER_ADMIN`은 `최고 관리자`, `OPERATOR`는 `관리자`로 표시한다.
- 로그아웃 버튼은 기존 `useAuth().logout()`을 호출한 뒤 `ROUTE_PATHS.LOGIN`으로 이동한다.
- 메뉴는 기존 `ROUTE_PATHS`와 `NavLink`의 `end` 설정을 그대로 사용한다.
- 아이콘 라이브러리는 추가하지 않는다. 기존 헤더와 같은 방식의 접근성 비노출 인라인 SVG를 사용한다.

## 반응형 및 접근성

- 데스크톱에서 사이드바는 기존 `220px` 너비와 `100svh` 높이를 유지한다.
- 좁은 화면에서는 기존 미디어 쿼리에 따라 사이드바가 문서 흐름으로 돌아가며 계정 카드는 메뉴 다음에 표시된다.
- 모든 메뉴와 로그아웃 버튼은 키보드 포커스 상태를 제공한다.
- 장식 아이콘에는 `aria-hidden="true"`와 `focusable="false"`를 적용하고, 로그아웃 버튼에는 명확한 접근성 이름을 제공한다.
- 긴 계정 이름은 한 줄 말줄임 처리해 사이드바 너비를 넘지 않게 한다.

## 검증

프로젝트에는 자동화 테스트 러너가 없으므로 새 테스트 의존성은 추가하지 않는다. 다음 검증을 수행한다.

- `npm run lint`
- `npm run build`
- `npm run dev:mock` 브라우저 스모크 테스트
  - 각 메뉴 아이콘과 활성 메뉴 스타일
  - 기존 경로 이동
  - 주요 현황 제거
  - 계정 카드 하단 정렬과 낮은 화면 높이에서의 스크롤
  - 로그아웃 버튼의 기존 인증 흐름 연결
  - 메인 콘텐츠 너비와 배치 유지
