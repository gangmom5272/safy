# 관리자 홈 헤더 상태 정보 설계

## 목표

관리자 공통 헤더에서 중복 계정 UI와 보조 브랜드 문구를 제거하고, 홈 화면 제목 옆에 서울 기준 현재 시각과 실제 대시보드 데이터의 마지막 정상 갱신 시각을 표시한다. 사이드바 브랜드와 메인 헤더의 하단선을 동일한 높이에 구조적으로 정렬하되 사이드바 메뉴와 메인 콘텐츠는 변경하지 않는다.

## 범위

- `frontend-admin/src/components/layout/AdminHeader.tsx`
  - 우측 계정 트리거와 드롭다운을 제거한다.
  - `SAFY Admin Console` 문구를 제거한다.
  - 홈 경로에서만 현재 시각과 갱신 상대 시간을 표시한다.
  - 긴급 위험 알림 버튼과 모달은 기존 동작을 유지한다.
- `frontend-admin/src/layouts/AdminLayout.tsx`
  - 마지막 정상 갱신 시각을 관리하고 헤더와 홈 페이지 사이의 전달 경계를 제공한다.
- `frontend-admin/src/pages/dashboard/DashboardPage.tsx`
  - 제보와 실시간 연결 조회가 모두 성공한 때만 마지막 갱신 시각을 기록한다.
  - 실시간 신호로 재조회가 성공하면 같은 방식으로 갱신한다.
- `frontend-admin/src/utils/adminDate.ts`
  - 서울 기준 `YYYY-MM-DD HH:mm:ss` 포맷과 상대 갱신 문구 계산 함수를 추가한다.
- `frontend-admin/src/index.css`
  - 공통 헤더 높이와 헤더 상태 정보, 반응형 스타일을 적용한다.

지도, 마커, 최근 배정 제보, 실시간 연결 카드, WebRTC, 사이드바 메뉴·아이콘·라우팅, 사이드바 하단 계정 카드, 긴급 위험 알림 기능은 수정하지 않는다.

## 담당 구역 연동 제외

현재 `/api/v1/users/me` 응답에는 담당 구역이 없고 백엔드 필드명도 합의되지 않았다. 따라서 이번 작업에서는 사이드바의 `성동구` 표시와 `AdminUser` 타입을 변경하지 않는다. 백엔드와 필드명, null 정책, 짧은 구역명과 관제센터 이름의 반환 범위를 합의한 후 별도 작업으로 연결한다.

## 헤더 구조

공통 헤더는 왼쪽 제목 영역과 오른쪽 긴급 알림 영역으로 구성한다.

- 모든 관리자 경로: 해당 페이지 제목을 표시한다.
- 홈 경로: 제목 오른쪽에 서울 기준 현재 시각, 얇은 세로 구분선, 마지막 갱신 상대 시간을 추가한다.
- 오른쪽: 기존 긴급 위험 알림 버튼만 유지한다.
- 기존 관리자 이름 버튼, 프로필 드롭다운, 헤더 로그아웃 SVG와 관련 상태·이벤트는 제거한다. 인증 상태와 사이드바 로그아웃은 유지한다.

## 시각 정렬

전역 토큰 `--admin-header-height: 83px`을 추가한다.

- `.admin-header`는 이 높이를 사용하고 내부 요소를 세로 중앙 정렬한다.
- `.admin-sidebar`의 위쪽 padding을 제거하고 좌우·아래 padding은 기존 `18px`을 유지한다.
- `.admin-sidebar__brand`가 공통 높이를 직접 사용하도록 해 브랜드 하단선과 메인 헤더 하단선이 같은 Y축에 놓이게 한다.
- 브랜드 다음의 기존 `18px` gap을 유지하므로 데스크톱 메뉴 시작 위치는 바뀌지 않는다.
- 사이드바 너비 `220px`과 메인 그리드는 유지한다.

## 현재 시각

`AdminHeader`는 홈 경로일 때 `Date` 상태를 1초 간격으로 갱신한다. 경로가 홈이 아니면 interval을 만들지 않으며, effect cleanup에서 interval을 제거한다.

표시는 `Intl.DateTimeFormat`과 `formatToParts`를 사용해 `ko-KR`, `Asia/Seoul` 기준 `YYYY-MM-DD HH:mm:ss` 형식을 명시적으로 조립한다. 새로운 날짜 라이브러리는 추가하지 않는다.

## 마지막 갱신 시각

`AdminLayout`은 `lastDashboardUpdatedAt: number | null` 상태와 안정적인 기록 함수를 소유한다. `Outlet` context로 기록 함수를 `DashboardPage`에 전달하고, `AdminHeader`에는 현재 값을 prop으로 전달한다.

`DashboardPage.loadDashboard()`에서 제보와 실시간 연결 요청이 모두 성공하고 상태 반영이 끝난 직후 `Date.now()`를 기록한다. 실패 시에는 값을 변경하지 않아 마지막 정상 시각을 유지한다. 초기 조회와 실시간 신호 재조회가 동일한 함수를 사용하므로 별도 중복 상태를 만들지 않는다.

상대 문구 기준은 다음과 같다.

- 값 없음: `갱신 대기`
- 10초 미만: `방금 갱신`
- 10초 이상 60초 미만: `갱신 N초 전`
- 1분 이상 60분 미만: `갱신 N분 전`
- 1시간 이상 24시간 미만: `갱신 N시간 전`
- 24시간 이상: `갱신 N일 전`

## 반응형

- 데스크톱에서는 제목, 현재 시각, 갱신 정보가 한 행에 놓인다.
- 기존 `760px` 이하 레이아웃에서는 헤더가 세로로 쌓이되 제목과 현재 시각은 유지한다.
- 공간이 부족한 좁은 화면에서는 갱신 정보와 구분선을 숨겨 긴급 알림과 겹치지 않게 한다.
- 사이드바 너비를 줄이거나 메인 콘텐츠를 재배치하지 않는다.

  - 긴급 위험 알림 버튼 및 모달 유지
  - 현재 시각의 정확한 형식과 1초 변화
  - 초기 조회 성공 및 실시간 재조회 시 갱신 문구 변화
  - 데스크톱에서 두 하단선의 Y축 일치
  - 좁은 화면에서 겹침 없음
  - 사이드바 메뉴 위치·너비와 홈 콘텐츠 배치 유지
